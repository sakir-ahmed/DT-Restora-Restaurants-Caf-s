# Documentation

## Specification

| File | Purpose | Applies to |
| ---- | ------- | ---------- |
| [prd.md](prd.md) | Product requirements: roles, modules, business rules, scope | both |
| [architecture.md](architecture.md) | Tech stack, folder structure, coding rules, Definition of Done | web-app |
| [api.md](api.md) | API conventions, endpoints, payment gateway flows | both (contract) |
