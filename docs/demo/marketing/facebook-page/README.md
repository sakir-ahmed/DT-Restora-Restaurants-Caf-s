# DT Restora Facebook page kit

Everything needed to create and launch the **DT Restora** Facebook page.

| Item | Where |
|---|---|
| Logo, profile pictures, covers, event cover, intro and pinned posts | `assets/` (see `06-graphics-guide.md`) |
| Page name, username, category, contact, services, offer | `01-page-identity.md` |
| Intro (bio), About, mission, hashtags in English and Bangla | `02-bio-about-story.md` |
| Messenger greeting, auto-replies, FAQ, saved replies, comment replies | `03-messenger-and-replies.md` |
| Step-by-step setup checklist | `04-setup-checklist.md` |
| First 30 days of posts with exact folders | `05-launch-30-days.md` |
| Graphics sizes, safe zones, how to regenerate | `06-graphics-guide.md` |
| Groups, partners, ads, rules and SEO | `07-growth-and-rules.md` |

Start here:

1. Read `01-page-identity.md` and decide the name and username.
2. Follow `04-setup-checklist.md` from top to bottom.
3. Publish the posts in `05-launch-30-days.md`.

Related folders (one level up): `../social-media-posts/posts/` has 145 ready posts with captions, `../social-media-posts/brand-assets/` has banners, stories and ads, `../social-media-posts/campaign/` has the 90-day plan for 100 sales, and `../product-screenshots/` has screenshots for photo albums.

Items marked `[ADD]` in these files are facts only you can fill in (address, opening hours, privacy policy link, your company story). Facebook changes its menus often, so treat menu names as a guide.
